My Projects

LocateVehicle – Vehicle Tracking System

This is a complete web-based vehicle tracking project built using Angular and Spring Boot. The system allows admin and drivers to login and track vehicle locations using free OpenStreetMap and Leaflet.js without using paid Google APIs. It includes features like driver management, admin dashboard, live location sharing, ride start/end, and tracking history. This project focuses on real-time location management and practical implementation of frontend-backend integration.

SecureKey – Database Security Project

SecureKey is a security-based project idea focused on protecting database clusters and sensitive user information. It aims to implement authentication, authorization, and encryption techniques to prevent unauthorized access. The project demonstrates understanding of cybersecurity concepts and secure application design.

CyberSathi – Ongoing Development

CyberSathi is currently an ongoing project and startup idea. It is being developed as a digital platform for small local shopkeepers to manage their business digitally. The goal is to provide features like digital billing, inventory management, customer records, and simple delivery management. This project is under planning and development phase and will be expanded step by step.
